# Book API

A lightweight RESTful API for managing a collection of books, built with **FastAPI**, **SQLAlchemy**, and **PostgreSQL**. It supports core CRUD operations, secure configuration via environment variables, data validation using Pydantic, and automated testing with `pytest`.

## Features

- **Persistent Storage:** Data is stored securely in a **PostgreSQL** database using **SQLAlchemy ORM**.
- **CRUD Operations:** Create, read, update, and delete books with proper HTTP status codes.
- **Partial Updates:** Update selected book fields dynamically using `PATCH`.
- **Environment Security:** Database credentials and sensitive configurations are managed safely using `.env` files and `python-dotenv`.
- **Data Validation:** Request data is strictly validated with **Pydantic** models.
- **Interactive Documentation:** Explore and test the API directly through automatically generated Swagger UI and ReDoc.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/neo-0706/book-api
cd book-api
```

### 2. Create and activate a virtual environment

**Windows (PowerShell)**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**Windows (Command Prompt)**

```cmd
python -m venv .venv
.venv\Scripts\activate.bat
```

**macOS / Linux**

```bash
python -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Configure Environment Variables

Create a `.env` file in the root directory of the project and specify your PostgreSQL connection URL:

```env
DATABASE_URL=postgresql+psycopg2://postgres:YOUR_PASSWORD@localhost:5432/book_db
```

*(Replace `YOUR_PASSWORD` with your actual PostgreSQL password and `book_db` with your database name).*

### 5. Start the development server

```bash
uvicorn main:app --reload
```

The API will be available at:

- API base URL: `http://127.0.0.1:8000`
- Interactive Swagger UI: `http://127.0.0.1:8000/docs`
- ReDoc documentation: `http://127.0.0.1:8000/redoc`

## API Endpoints

| Method | Endpoint | Description | Success response |
|---|---|---|---|
| `GET` | `/books` | Retrieve all books | `200 OK` |
| `POST` | `/books` | Create a book | `201 Created` |
| `GET` | `/books/{book_id}` | Retrieve a book by ID | `200 OK` |
| `PATCH` | `/books/{book_id}` | Update selected fields | `200 OK` |
| `DELETE` | `/books/{book_id}` | Delete a book | `204 No Content` |

### Book schema

A book contains the following fields:

| Field | Type | Rules |
|---|---|---|
| `id` | Integer | Auto-incremented primary key generated by PostgreSQL |
| `title` | String | Must not be empty |
| `author` | String | Must not be empty |
| `published_year` | Integer | Must be greater than zero |

### Example: Create a book

**Request**

```http
POST /books
Content-Type: application/json
```

```json
{
  "title": "Clean Code",
  "author": "Robert C. Martin",
  "published_year": 2008
}
```

**Example response — `201 Created`**

```json
{
  "id": 1,
  "title": "Clean Code",
  "author": "Robert C. Martin",
  "published_year": 2008
}
```

### Example: Update a book

`PATCH` accepts only the fields you want to change. Fields omitted from the request remain unchanged.

```http
PATCH /books/1
Content-Type: application/json
```

```json
{
  "title": "Clean Code: Updated Edition"
}
```

### Example: Error response

Requesting a book ID that does not exist returns `404 Not Found`.

```json
{
  "detail": "Book not found"
}
```

Invalid request data is rejected with `422 Unprocessable Entity`.

## Implementation Notes

- **Database Persistence:** Books are permanently stored in a PostgreSQL database managed via SQLAlchemy models and sessions.
- **Dependency Injection:** Database sessions are handled cleanly using FastAPI's dependency injection (`Depends(get_db)`).
- **Partial updates:** `PATCH` updates only fields included in the request payload using dynamic attribute setting.
- **Security:** Credentials are fully decoupled from source code through environment variables.
