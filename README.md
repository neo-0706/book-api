# Book API

A lightweight RESTful API for managing a collection of books, built with **FastAPI** and **Pydantic**. It supports the core CRUD operations, validates incoming data, returns clear HTTP errors, and provides interactive API documentation out of the box.

## Features

- **Create** a book and receive its generated ID.
- **Read** all books or retrieve a single book by ID.
- **Update** selected book fields using `PATCH`.
- **Delete** a book by ID.
- **Validate** request data with Pydantic models.
- **Handle errors** with appropriate HTTP status codes.
- **Explore the API** through automatically generated Swagger UI.

## Tech Stack

- [Python](https://www.python.org/)
- [FastAPI](https://fastapi.tiangolo.com/)
- [Pydantic](https://docs.pydantic.dev/)
- [Uvicorn](https://www.uvicorn.org/)
- [Pytest](https://docs.pytest.org/) and [HTTPX](https://www.python-httpx.org/) for testing

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/neo-0706/book-api
cd book-api
```

Replace `https://github.com/neo-0706/book-api` with the URL of your Git repository.

### 2. Create and activate a virtual environment

**Windows (PowerShell)**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**Windows (Command Prompt)**

```cmd
python -m venv .venv
.venv\Scripts\activate.bat
```

**macOS / Linux**

```bash
python -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Start the development server

```bash
uvicorn main:app --reload
```

The API will be available at:

- API base URL: `http://127.0.0.1:8000`
- Interactive Swagger UI: `http://127.0.0.1:8000/docs`
- ReDoc documentation: `http://127.0.0.1:8000/redoc`

## API Endpoints

| Method | Endpoint | Description | Success response |
|---|---|---|---|
| `GET` | `/books` | Retrieve all books | `200 OK` |
| `POST` | `/books` | Create a book | `201 Created` |
| `GET` | `/books/{book_id}` | Retrieve a book by ID | `200 OK` |
| `PATCH` | `/books/{book_id}` | Update selected fields | `200 OK` |
| `DELETE` | `/books/{book_id}` | Delete a book | `204 No Content` |

### Book schema

A book contains the following fields:

| Field | Type | Rules |
|---|---|---|
| `id` | Integer | Generated by the API |
| `title` | String | Must not be empty |
| `author` | String | Must not be empty |
| `published_year` | Integer | Must be greater than zero |

### Example: Create a book

**Request**

```http
POST /books
Content-Type: application/json
```

```json
{
  "title": "Clean Code",
  "author": "Robert C. Martin",
  "published_year": 2008
}
```

**Example response — `201 Created`**

```json
{
  "id": 1,
  "title": "Clean Code",
  "author": "Robert C. Martin",
  "published_year": 2008
}
```

### Example: Update a book

`PATCH` accepts only the fields you want to change. Fields omitted from the request remain unchanged.

```http
PATCH /books/1
Content-Type: application/json
```

```json
{
  "title": "Clean Code: Updated Edition"
}
```

### Example: Error response

Requesting a book ID that does not exist returns `404 Not Found`.

```json
{
  "detail": "Book not found"
}
```

Invalid request data is rejected with `422 Unprocessable Entity`.

## Implementation Notes

- **In-memory storage:** Books are kept in a Python dictionary. Data is lost when the server restarts.
- **Generated IDs:** IDs start at `1` and increment when books are created.
- **Partial updates:** `PATCH` updates only fields included in the request.
- **No database required:** This implementation is intentionally lightweight and suitable for a small learning task or prototype.
